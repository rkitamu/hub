# hub-env — {{ENV_NAME}}

この環境の司令塔の作業場所。地図は `MAP.md`、エージェントの定義と herdr のレイアウトは `hub.toml` にある。

## 頼み方

環境の `hub-env` ワークスペースにいる司令塔（commander）に、普段の言葉で頼む。ファイルを変更する依頼や込み入った相談は、司令塔が作業にして、作業名のタブに lead を立てる。作業の中身は、そのタブで lead と直接話す。

| 頼み方 | 誰が何をするか |
|---|---|
| 「<子リポジトリ> の使い方を教えて」 | 司令塔が、地図と子のドキュメントを読んで答える |
| 「全体の状況を見せて」 | 司令塔が、`hub-status` でエージェント、未コミットの変更、進行中の作業、期限の近い TODO をまとめる |
| 「地図とずれていないか見て」 | 司令塔が、`hub-check` で `MAP.md`、`hub.toml`、実態を照らし合わせる |
| 「#30 を任せて」「<子リポジトリ> の xxx を直して」「hub の xxx を直して」「地図に xxx を足して」 | 司令塔が、作業名と指示文を示して `hub-work start` し、作業名のタブに lead を立てる |
| （作業のタブで）計画と進め方の相談 | lead が計画を示し、承認をもらってから、子リポジトリに crew を立てて振る（`hub-lead assign`） |
| 「#30 の進み具合は？」 | 司令塔が、作業の `status.md` を読んで答える。作業のタブで lead に聞いてもよい |
| （作業のタブで）「閉じて」 | lead が結果を報告し、OK をもらってから `hub-lead finish` で crew と自分のタブを閉じ、記録を archive へ移す。未コミットの変更があれば止めて相談する |
| 「止まった作業を再開して」 | 司令塔が、`hub-work resume` で lead と crew のタブを立て直す |
| 「この指摘を今後のルールにして」 | 効く範囲に合わせて置き場所の案を示し、OK をもらってから反映する |
| 「全部立て直して」 | herdr のとき、`herdr-reset` を実行する（自分で打ってもよい）。作業のタブも閉じるので、あとで再開する |
| 「<ワークスペース> だけ立て直して」 | herdr のとき、`herdr-reset <ワークスペース>` を実行する。作業のタブは残る |
