# コミット

- main / master へ直接コミットしない。作業ブランチを切ってからコミットする。
- remote があるリポジトリは、作業ブランチを push し、PR を介して main へ入れる。main へ直接 push しない。
- remote が無いリポジトリは、作業ブランチをローカルで main へマージする。コンフリクトを解消したら `git commit` ではなく `git merge --continue` で完了する。
- 例外は、作業文書や TODO のデータのように、ローカルでのみバージョン管理するためのリポジトリだけ。これらは main へ直接コミットしてよい。remote が無いだけのコードや設定のリポジトリは例外にしない。
- このルールは、コミットしてよいかどうかを決めない。コミット・push・PR の作成・マージの可否は、ユーザーの指示とリポジトリのルールに従う。
